# NeuroScan

## Overview
NeuroScan AI is a full-stack clinical decision support application developed for neurological disease risk assessment. The system integrates machine learning models with an interactive web interface to provide predictive insights from patient data.

> **Disclaimer**
> This project was developed as an academic proof-of-concept to demonstrate the application of artificial intelligence in neurological clinical decision support. It is not intended for clinical use and should not replace professional medical judgment or diagnostic procedures.

- Interactive web-based interface
